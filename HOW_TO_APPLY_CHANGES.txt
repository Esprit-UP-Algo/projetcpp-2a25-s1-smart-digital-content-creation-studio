└────────────────────────────────────────────────────────────────┘
In Qt Creator:
  - Press F5 (Run)

┌────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                │
└────────────────────────────────────────────────────────────────┘

Problem: QR code still shows old format (Code, Budget, etc.)
Solution:
  ✓ Make sure you did "Clean All" before rebuilding
  ✓ Completely close and restart Qt Creator
  ✓ Delete the entire "build" folder manually
  ✓ Rebuild the project from scratch

Problem: Application won't compile
Solution:
  ✓ Check for compile errors in the "Compile Output" panel
  ✓ Make sure all files are saved (Ctrl+S)
  ✓ Verify that projet.h and projet.cpp are properly updated

Problem: QR code is empty or shows "Remplissez les champs"
Solution:
  ✓ Make sure the project has a title and deadline set
  ✓ Check that the form fields are properly filled
