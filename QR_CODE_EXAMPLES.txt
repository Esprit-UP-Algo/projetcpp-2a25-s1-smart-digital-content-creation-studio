  ❌ Project 'Marketing Campaign' deadline EXPIRED 3 day(s) ago!

Scenario 4: Due in Few Days

KEY DIFFERENCES:
═══════════════════════════════════════════════
OLD                          NEW
─────────────────────────────────────────────
✗ One project only           ✓ All urgent projects
✗ Requires selection         ✓ No selection needed
✗ Shows Code, Budget         ✓ Only project name
✗ Shows raw date             ✓ Shows days remaining
✗ No urgency indicator       ✓ Visual emoji indicators
✗ Technical info             ✓ Human-friendly messages


WHAT'S INCLUDED IN QR CODE:
═══════════════════════════════════════════════
✓ Project Title (Name)
✓ Days until expiration (e.g., "in 2 days")
✓ Visual indicators (⚠️, 🔴, ⏰, ❌)
✓ Total count of urgent projects

✗ NOT included anymore:
  - Project Code
  - Budget amount
  - Raw deadline date
  - Other technical details


BENEFITS:
═══════════════════════════════════════════════
1. SIMPLER TO READ
   - No technical jargon
   - Clear, plain language messages
   
2. ACTIONABLE INFORMATION
   - Immediately know how many days left
   - See which projects are most urgent
   
3. VISUAL PRIORITY
   - Red circle (🔴) = Due today
   - Warning (⏰) = Due soon
   - X mark (❌) = Already expired
   
4. COMPREHENSIVE
   - See ALL urgent projects at once
   - No need to generate multiple QR codes
   
5. USER FRIENDLY
   - No selection required
   - One click to generate
   - Easy to scan and understand
